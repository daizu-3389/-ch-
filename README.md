# ２ちゃん風掲示板

超初心者向けに作られたシンプルな掲示板システムです！

## 📚 このプロジェクトについて

これは以下の技術で作られています：
- **バックエンド**: Node.js + Express（サーバー）
- **フロントエンド**: React（画面）
- **データ保存**: 当面はJSONで保存（簡易版）

## 🚀 はじめに

### 必要なもの
1. **Node.js** のインストール
   - https://nodejs.org/ から LTS版 をダウンロード・インストール
   - ターミナルで `node --version` と打ってバージョンが表示されればOK

### セットアップ手順

#### 1. バックエンドをセットアップ
```bash
cd backend
npm install
npm start
```
→ ターミナルに `✅ Server is running on http://localhost:5000` と出れば成功！

#### 2. フロントエンドをセットアップ（別のターミナルで）
```bash
cd frontend
npm install
npm start
```
→ ブラウザが自動で開いて、画面が見えたら成功！

## 📖 基本知識

### フロントエンド vs バックエンド

| 部位 | 役割 | 例 |
|------|------|-----|
| **フロントエンド** | ユーザーが見る画面 | ボタン、テキストボックス、スレッド一覧 |
| **バックエンド** | 裏で動く処理・保存 | データを保存、スレッドを検索 |

### 通信の流れ
```
[ユーザーが画面でボタン押す]
      ↓
[フロントエンド（React）が反応]
      ↓
[バックエンド（Express）にリクエスト送信]
      ↓
[バックエンドがデータベースを操作]
      ↓
[フロントエンドに結果を返す]
      ↓
[画面が更新される]
```

## ❓ トラブルシューティング

### ポート 5000 が既に使われている場合
```bash
# backend/.env ファイルを作成して以下を追加
PORT=3001
```

### `npm: command not found` が出た
Node.js が正しくインストールされていません。
上記の「必要なもの」の手順をもう一度確認してください。
